# MahaswinBTP

This repository brings together the two simulator codebases used for the CXL BTP:

- `SimCXL/`: the current SimCXL research working tree, including local modifications.
- `OCEAN/`: the OCEAN CXL emulation framework used for faster full-workload experiments and the planned PIPM prototype. Imported from `fam-emu/OCEAN` at commit `c712cfa4194a041a3f390626a2abc150a29e4cbc`.

Large generated builds, VM images, and runtime results are intentionally excluded from version control.
